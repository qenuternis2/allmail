# Инструкции для агентов

Перед изменениями изучите `README.md` и относящиеся к задаче документы в `docs/`.
Команды сборки и тестов, архитектура и ограничения WebView2 описаны в `README.md`.

## Проверка веб-интерфейса

- При разработке и изменении веб-интерфейса используйте
  [web-design-guidelines](.agents/skills/web-design-guidelines/SKILL.md)
  для проверки результата перед завершением работы. Это относится и к HTML/CSS/JS
  интерфейсам, встроенным в WebView2.
- При запросах аудита UI, UX или доступности явно применяйте этот skill:
  сообщите о его использовании, прочитайте `SKILL.md` и проверьте относящиеся
  к запросу файлы. Для нативного WPF-интерфейса учитывайте применимость правил;
  требования к DOM, HTML и ARIA относятся к веб-интерфейсу.
- Перед каждой проверкой загрузите актуальные правила по адресу из `SKILL.md`.
  Если загрузка недоступна, сообщите об ограничении и необходимых для доступа
  доменах; не заявляйте, что проверка по актуальным правилам выполнена.

Источник, зафиксированная версия и порядок обновления skill описаны в
[README skill](.agents/skills/web-design-guidelines/README.md).
