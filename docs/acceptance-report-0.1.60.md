# Приёмка SecureBrowser 0.1.60

Дата: 8 октября 2026. Добавлена настройка SmartScreen для каждого профиля,
включённая по умолчанию. Пользователь явно согласовал возможность её отключения.

## Изменение

Настройки профиля → Защита → Проверка репутации → Включить SmartScreen.
Снятие галочки отключает репутационные проверки сайтов и скачиваемых файлов
для общей папки данных данного профиля, после закрытия и повторного открытия.
Уже начатые загрузки нужно начать заново. Системные настройки и антивирус
Windows не изменяются. Это не отдельная настройка только для загрузок.
Проверка опасного типа файла работает независимо: на том же FindCopy EXE
вместо «isn't commonly downloaded» получено «this type of file can harm
your device». Отдельная блокировка типа файла не обходится. Автоматическое завершение
всех EXE не обещается.

Настройка применяется до явной навигации или загрузки во всех production
контроллерах: основной, новые/восстановленные/всплывающие вкладки, служебный
контроллер разрешений, окно проверки отпечатка. Проверяется readback свойства.
Несовместимый Runtime не обходится неофициальными browser flags.
При ошибке настройки профиль/контроллер не продолжает открытие сайта.

SQLite schema 8 добавляет boolean с DEFAULT 1; миграция выполняется
транзакционно с резервной копией прежней базы. Старые snapshots и импорты
сохраняют включённую проверку. Значение сохраняется в ревизиях и переносится
через необязательное поле reputationCheckingEnabled формата настроек v1.
Импорт отключённой проверки показывает пояснение перед подтверждением.
Публичные интерфейсы браузера/загрузок и выбор пути сохранены.

## Границы

Отключённый SmartScreen не доказывает безопасность файла. Приложение не
выбирает Keep/Run и не запускает скачанные EXE. Проверка конкретного файла
проводится в одноразовом профиле Windows 11; пользовательские данные не используются.
Антивирус и политики Windows могут независимо вмешиваться в загрузки.
Системная настройка отключённого SmartScreen имеет приоритет над запросом
включить его в приложении; диагностический отчёт называет значение requested.
Остальные ручные пункты и ограничения сохранены из [0.1.59](acceptance-report-0.1.59.md).

[Microsoft: IsReputationCheckingRequired](https://learn.microsoft.com/en-us/dotnet/api/microsoft.web.webview2.core.corewebview2settings.isreputationcheckingrequired?view=webview2-dotnet-1.0.4258.31).
