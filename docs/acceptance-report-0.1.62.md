# Приёмка SecureBrowser 0.1.62

Изменения интерфейса проверены в commit
`46b7a296d3414c2d2f0ea25cfdd198c6c1abe183` (версия 0.1.61).
Версия 0.1.62 добавляет этот обязательный документ для упаковки и обновляет
метаданные версии; код приложения совпадает с проверенным commit. Конвейер
также проверяет наличие отчёта до начала дорогой сборки и нативных тестов.
Первый выпуск 0.1.61 остановился при копировании отсутствующего отчёта
приёмки, после успешной сборки и нативных тестов. ZIP не был опубликован.

## Выполненные проверки изменений интерфейса

- Локально: обе сборки, .NET analyzers и сборка Windows smoke без предупреждений;
  **678/678** тестов ядра и **109/109** JavaScript-тестов.
- [Windows 11 push CI](https://github.com/qenuternis2/allmail/actions/runs/38048455611)
  и [PR CI](https://github.com/qenuternis2/allmail/actions/runs/38048459183):
  полный успешный прогон, включая публикацию обеих сборок, native WebView2,
  DPI и настоящий per-user installer.
- [Первый release CI](https://github.com/qenuternis2/allmail/actions/runs/38049227619):
  сборка и native WebView2 прошли; упаковка остановилась из-за отсутствующего
  документа. Этот run целиком не является успешным выпуском.
- Проверены связанные подписи и доступные имена полей, клик по подписи,
  выбор вкладки с первой ошибкой, фокус и ошибки рядом с полями.
- Проверены доступные имена вкладок и состояние выбора, перестановка через
  меню и Ctrl+Shift+PgDn, сохранение порядка, выбранного controller и содержимого
  страницы. Существующие drag/drop, закрытие вкладок и восстановление сохранённой
  сессии также прошли.
- Проверены live-region свойства и доступный текст при паузе и завершении
  настоящей тестовой загрузки. Побайтовый прогресс не вызывает объявления.
- Production HTML/CSS и renderer страницы диагностики проверены в настоящем
  WebView2 на ширинах **320/480/900 CSS px**: заголовки строк, имена таблиц,
  live status, main landmark, отсутствие горизонтального переполнения и
  читаемая ширина значений. Проверена тёмная схема. Использованы синтетические
  данные; сборщики и внешние запросы этой страницы не запускались.
- Актуальные `web-design-guidelines` загружены; контраст второстепенного текста
  диагностики повышен до 5,49:1, предупреждения — до 7,10:1 на белом фоне.

## Покрытие и ограничения

Все Windows-проверки выполняются на **Windows 11 ARM64 Workstation**;
приложение win-x64 работает через эмуляцию x64. Windows Server не используется.
Это не отдельный прогон на оборудовании Windows 11 x64.

DPI 100/125% проверены со сменой масштаба ОС; 150/200% — через synthetic
WM_DPICHANGED. На этих двух масштабах смена DPI Windows не выполнена.
Проверены production shell, свёрнутая панель профилей, создание, пять вкладок
настроек, группы и подтверждение. Границы покрытия малого рабочего стола
сохраняются: [описание DPI fixture](windows11-dpi-2026-10-07.md).

Озвучивание Narrator и другими скринридерами требует ручной проверки.
Автотесты проверяют программные связи, имена, состояния, фокус и live-region
настройки; это не полная сертификация доступности.

## Проверка точного выпуска

Конвейер `windows-proxy-release` повторяет сборку, тесты, native WebView2,
DPI, проверку версии EXE и install/update/uninstall перед публикацией
точного тега `v0.1.62`. В ZIP включены свежие `webview2-graphics.log` и
`installer.log`; итоговый статус workflow и эти журналы подтверждают результаты
конкретного выпуска, а не только проверки исходных UI-изменений выше.

Сетевые и privacy-ограничения WebView2 и экспериментального прокси сохраняются.
Исправления интерфейса не подтверждают отсутствие утечек или полный контроль
отпечатка. Подпись дистрибутива зависит от предоставленного сертификата;
без настройки подписи сборка остаётся неподписанной, как ранее.
