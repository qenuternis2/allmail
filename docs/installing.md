# Установка, обновление и удаление SecureBrowser

Для Windows 11 x64 предлагаются два файла: установщик
`SecureBrowser-<версия>-setup-win-x64.exe` и переносимый архив
`SecureBrowser-<версия>-proxy-win-x64.zip`. Обе поставки содержат .NET.
WebView2 Evergreen Runtime устанавливается отдельно; ссылка на Microsoft
показывается при его отсутствии. Общий Runtime не удаляется вместе с программой.

Установщик работает без повышения прав, для текущего пользователя, в
`%LOCALAPPDATA%\Programs\SecureBrowser`. Повторная установка обновляет программу.
Данные сохраняются в прежнем `%LOCALAPPDATA%\ProtonProfiles`, поэтому смена
названия и переход с ZIP не требуют переноса сессий. Перед обновлением закройте
программу. Установщик предлагает закрыть использующие её файлы процессы.

Для ZIP распакуйте весь архив и запускайте `SecureBrowser.exe`. Не переносите
EXE отдельно от DLL и других каталогов. Обновляйте программные файлы при закрытом
приложении; не заменяйте каталог пользовательских данных.

При удалении выберите:

- «Нет» — удалить программу и сохранить профили для следующей установки;
- «Да» — удалить локальные профили, cookies, историю, настройки, журналы,
  локальные базы GeoIP и принадлежащие профилям секреты Windows Credential Manager;
- «Отмена» — прекратить удаление.

Вложения, сохранённые за пределами каталога данных, сохраняются. Файлы, которые
пользователь самостоятельно положил внутрь `%LOCALAPPDATA%\ProtonProfiles`,
входят в удаляемые данные. Очистка не следует по ссылкам/junction. Другие
запущенные экземпляры блокируют её; при оставшемся Runtime-процессе либо
невозможности проверить процессы данные не удаляются. Заблокированные файлы
могут оставить частичную очистку: программа сообщает об этом, а деинсталлятор
сохраняет возможность повторить операцию. Другие браузерные процессы не убиваются.

Тихое удаление по умолчанию сохраняет данные. Только явный параметр
`unins000.exe /VERYSILENT /REMOVEUSERDATA` включает их удаление.
Не используйте этот параметр, если нужно сохранить сессии.

Сборка установщика: `./scripts/Build-Installer.ps1` после `./build.ps1 -Publish`.
Компилятор Inno Setup 7.1.0 закреплён SHA-256 и проверяется Authenticode перед
установкой. `./scripts/Test-Installer.ps1 -Installer <EXE>` проверяет установку,
повторную установку и оба режима удаления на пустом Windows runner; тест
отказывается перезаписывать существующие пользовательские данные.

Выпуск без сертификата **не подписан**. Для реальной подписи предусмотрен
`scripts/Sign-Release.ps1` (PowerShell 7.5+ / .NET 9+): `SECUREBROWSER_SIGN_PFX` — путь к сертификату подписи
кода, `SECUREBROWSER_SIGN_PASSWORD` — его пароль. Скрипт проверяет назначение,
срок, наличие ключа и результат подписи с timestamp; самоподписанный сертификат
вместо доверенной подписи не создаётся. CI без этих настроек явно сообщает
`Signing not configured: release is unsigned`. SHA-256 поставляется для ZIP и EXE.
