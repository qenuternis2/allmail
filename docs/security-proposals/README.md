# Согласованные патчи аудита

Патчи здесь сохранены как история предложения к ревизии `bd8eb53`.
Пользователь согласовал их после аудита 7 октября 2026; изменения входят в
SecureBrowser 0.1.55. Применять их поверх текущих исходников повторно не нужно.

Runtime patch закрепляет SDK 10.0.112 и runtime 10.0.12. Фактическая реализация
Download patch дополнительно выделяет private `FinalizeDownloadPath`, чтобы
нативный тест проверял производственный диалог после выбора файла. Публичные
сигнатуры и штатный Win32 SaveFileDialog сохранены.

Результаты и остаточные риски: [аудит](../security-audit-2026-10-07.md),
[приёмка 0.1.55](../acceptance-report-0.1.55.md).
