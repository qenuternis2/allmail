WebRTC: синтетический стенд

Используйте отдельные тестовые профили. Стенд не обращается к публичным STUN/TURN и не читает почту.

Ожидаемая политика берётся из URL: ?expected=Block или ?expected=Allow; она должна совпадать с настройкой профиля.

Результаты API не подтверждают сетевую защиту. Для положительного контроля передачи данных выберите Allow и настройки сети среды выполнения.

Необязательные ICE servers — только принадлежащий вам STUN/TURN стенд. Пустой массив означает проверку локальных peers; это не проверка прокси. TURN-пароли не сохраняются в отчёт.

Для отдельной сетевой проверки с Allow + RestrictNonProxiedUdpExperimental задайте ICE servers и проверьте поведение с выбранным прокси, без него и при его отказе. Снимайте трафик с начала запуска процесса.
