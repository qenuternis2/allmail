# Улучшения отпечатка v0.1.4

В пользовательском отчёте браузер использовал Africa/Nairobi (+03:00), а IP был
геолокирован в Europe/Berlin (+02:00 на дату отчёта). Совпадение основной версии
154 скрывало предупреждение о Chrome-подобном UA и брендах Edge/WebView2.
ID отпечатка включал RTT, скорость сети и размеры окна и поэтому не был устойчивым.
Замаскированные адреса не позволяют установить утечку IPv4/IPv6 или прямой выход.

## Изменения

- Часовой пояс IANA задаётся отдельно для каждого профиля. Пустое поле — системный.
  Применяется нативным `Emulation.setTimezoneOverride` до целевой навигации
  основного окна, дочерних окон и диагностики. Функции Date/Intl не подменяются.
  Основное окно и диагностика проверяют Intl и зимнее/летнее смещение Date
  в собственном about:blank после NavigationCompleted. Ошибка применения
  блокирует открытие основного окна; дочерний контроллер остаётся ненавигированным
  до NewWindowRequested. Общая проверка workers и OOPIF не выполнена.
- SQLite v2 → v3: nullable BrowserTimeZoneId, резервная копия до миграции.
  Старые профили остаются с системным поясом. Настройка переносится импортом/экспортом;
  старые JSON v1 без этого поля принимаются. Данные браузера, разрешения,
  снимки ревизий и даты напоминаний сохраняются. Изменение требует перезапуска.
- Прокси-профили блокируются при внешних аргументах WebView2 из переменной среды
  или политики реестра, которые могут изменить выбранный маршрут. Ранее это
  проверялось только при экспериментальном ограничении UDP WebRTC.
- ID среды v2 исключает RTT/скорость, размеры окна, доступную область экрана
  и хранилище; отдельный stateFingerprintId описывает экран и соединение сейчас.
  Версия, аппаратные признаки, DPI, язык и часовой пояс могут менять ID среды.
  ID не измеряет уникальность и несопоставим с ID из предыдущего сборщика.
- Проверки UA сравнивают Chromium, бренд, платформу и HTTP/JavaScript представления.
  WebView2 показывается явно. Несовпадение страны IP и языка — информация,
  а не доказательство утечки. Уточнены ограничения permissions.query и шрифтов.
- Маршруты прокси, DNS, сеть WebRTC и полное покрытие контекстов явно NotPerformed.

## Проверки и ограничения

222 теста ядра и 18 JavaScript-тестов: валидация, сезонные смещения Berlin,
миграция v2/v1 с сохранением данных и резервной копией, перенос настройки,
перезапуск только нужного профиля, устойчивость ID при изменении RTT/окна,
расхождения UA/Client Hints/HTTP. Core и Experimental компилируются отдельно.
Автоматические тесты не проверяют выполнение CDP внутри Windows WebView2.

Для исходного немецкого выхода задайте Europe/Berlin и User-Agent «По умолчанию»,
перезапустите профиль и сохраните новый отчёт. Проверьте смену навигации и дочерние
окна, одновременно откройте профиль с другим поясом и убедитесь в изоляции.
На контролируемом стенде сравните Date/Intl в главном документе, same-origin,
cross-origin/OOPIF, dedicated/shared/service workers и после смены процесса.
Проверьте IPv4/IPv6, DNS и отказ прокси сетевым захватом по WEBRTC_FIX_REPORT.md.

Полная анонимность, несвязываемость профилей и отсутствие IP-утечек не заявляются.
Canvas/Audio/WebGL/WebGPU и шрифты остаются доступными. Блокировка WebRTC сохранена.
Для возврата к приложению со схемой v2 потребуется предмиграционная резервная копия
метаданных; папка данных WebView2 этой миграцией не изменяется.

# Тестовые профили и ограничение графики v0.1.5

В новом пользовательском отчёте от 03.10.2026 часовой пояс Europe/Berlin и смещение
+02:00 совпадают с IP, штатный UA содержит Edg и согласован с Client Hints.
Это наблюдение одной диагностической страницы. RTX 4060 по-прежнему доступна через
WebGL и WebGPU; CPU, память, Canvas, Audio и шрифты остаются видимыми.
IPv4 скрыт пользователем, IPv6 пуст: вывод о маршруте по этому файлу невозможен.

## Реализовано

- Отдельный тип Test и кнопка «Тестовый профиль…»: HTTP/HTTPS URL, порты, локальные
  стенды, переходы между сайтами и дочерние окна внутри профиля. Для каждого нового
  профиля создаётся свежий UUID и своя папка браузера; данные почтовых профилей
  не копируются. Почтовая политика разрешённых origin не расширяется.
- Новый профиль остаётся закрытым до выбора сети и настроек. Изменение URL
  перезапускает только этот профиль. Профиль Test без URL, например после импорта
  экспорта без адресов, заблокирован и не переключается на почту.
- Экспериментальное ограничение графики, включаемое отдельно:
  `--disable-webgl --disable-features=WebGPU,WebGPUService`. Два имени feature
  учитывают различия Chromium Runtime. Никакие модели GPU не выдумываются,
  Canvas 2D/Audio/CPU/память/шрифты не подменяются. Опция может нарушить 3D и карты.
  Полная строка сохраняет прокси и флаг WebRTC; внешние аргументы блокируют открытие.
  В owned about:blank до открытия основной страницы проверяется отсутствие
  WebGL-контекста у Canvas и OffscreenCanvas. WebGPU там не считается проверенным:
  ему требуется secure context. Дочерние контроллеры остаются ненавигированными.
- Отчёт v3 наблюдает главный документ и локальный dedicated worker: timezone,
  UTC offset, CPU/память, WebGL и выдачу WebGPU-адаптера. Статусы графики относятся
  только к наблюдаемым контекстам: Pass/Fail/NotPerformed/NotApplicable. Ошибка
  или таймаут не превращается в Pass. Worker и Blob URL освобождаются.
  Наблюдение не доказывает действие флага: API могли отсутствовать и без него.
- IPv4/IPv6 ответ валидируется отдельно; пустой ответ, таймаут и ошибка не
  подтверждают отсутствие IPv6 или прямого трафика. Проверки маршрутов, DNS,
  сети WebRTC и всех контекстов остаются NotPerformed.
- Сохранённый fingerprint JSON по умолчанию скрывает известные поля IP/hostname,
  address в сетевых наблюдениях и forwarded/IP HTTP-заголовки. Живой локальный
  отчёт не меняется. Галочка позволяет явный экспорт адресов. Частичный отчёт
  ошибки также маскируется; некорректный JSON не сохраняется как сырой fallback.
- Экспорт настроек по умолчанию исключает полный тестовый URL. Включение адресов
  прокси и тестовых URL выбирается отдельно. В общий отчёт диагностики URL не попадает.
- SQLite v3 → v4 с предмиграционной резервной копией. Существующие профили остаются
  Mail, графика RuntimeDefault. Данные браузера, разрешения, снимки и timezone сохраняются.

## Проверки

246 тестов ядра и 22 JavaScript-теста: политики навигации и запрещённых схем,
изоляция поколений и папок, URL/настройки/импорт без адресов, сохранение прокси и
WebRTC в аргументах, миграции v1/v2/v3, экспорт IP, WebGL readback, обработка IPv6,
исходы наблюдения графики и освобождение worker. Core и Experimental компилируются.
VM-тесты не проверяют выполнение browser flags и GUI в Windows WebView2.

На Windows создайте Test-профиль, настройте его до открытия сайта, проверьте
переходы на другой HTTP/HTTPS origin и child window. Измените URL и перезапустите;
убедитесь, что почтовый профиль сохранил свою политику и сессию. Сравните отпечаток
с включённой и выключенной графикой в отдельном тестовом профиле. Проверьте main,
same-origin/cross-origin/OOPIF, dedicated/shared/service workers, смену процесса
и одновременные профили с разными политиками. Полное покрытие не проверено.

Для возврата к приложению со схемой v3 потребуется резервная копия метаданных.
